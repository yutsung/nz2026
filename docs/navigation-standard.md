# 行程導航連結規範

本規範適用於「NZ 2026｜南島公路手札」的逐日行程頁，目的是讓每一頁在旅行途中都能獨立使用，並維持一致的操作方式。

## 1. 導航層級

1. **單一目的地**：放在對應的時間軸主條目右側，不集中到頁尾。
2. **一日完整路線**：有兩個以上停靠點且順序重要時，才放在時間軸下方，按鈕文字使用「完整路線」或能辨識方向的名稱。
3. **官方資訊**：活動、步道、市集、道路或天氣的官方網站不是導航連結；依內容關聯放在該條目附近或頁面下方。

## 2. 哪些條目要提供導航

- 使用者當天需要親自抵達、且名稱足以辨識的固定地點，應提供單點導航。
- 住宿、租還車地點、活動集合點、機場、市集、餐廳、採買與步道入口都屬於導航地點。
- 同一地點跨日重複時，每個使用到它的逐日頁都要再次提供，不要求使用者回前一頁尋找。
- 只有城市名稱、未指定店家的中途休息、飛行航段、機上活動或純提醒不提供單點導航。
- 候選地點可以提供導航，但條目文字仍須清楚標示「候選」或「視情況」。

## 3. 互動與版面

- 不把整個時間軸卡片設為超連結，避免手機上下滑動時誤觸。
- 在條目右側使用文字按鈕；按鈕名稱採「導航」、「住宿」、「採買」、「集合」、「步道」等可理解的動作或目的。
- 一個條目有多個目的地時，每個地點各有一個按鈕，順序須與條目文字相同。
- 頁尾不得重複已在條目內出現的單點導航。
- 連結一律在新分頁開啟，並使用 `rel="noopener"`。

## 4. Google Maps 連結格式

- 單點使用 Google Maps Search URL：
  `https://www.google.com/maps/search/?api=1&query=<具名地點>`
- 多站路線使用 Google Maps Directions URL，明確填入起點、終點、途經點與 `travelmode=driving`。
- 查詢文字至少包含店名或設施名及城市／國家；同名機率高時加入地址。
- 不使用短網址，讓目的地可在原始碼與審查時直接辨識。

## 5. 無障礙與行動裝置

- 每個導航按鈕必須有能獨立理解的 `aria-label`，例如「導航至 RealNZ Visitor Centre」。
- 按鈕需有清楚的鍵盤焦點狀態，文字與背景對比符合現有色彩系統。
- 長地名可以換行，但導航按鈕不得被擠出卡片；同一條目有多個按鈕時允許按鈕列換行。
- 新增或修改連結後，至少檢查一般手機寬度、短可視高度與深色頁面。

## 6. 發布前檢查

- Day 1–13 每頁逐項檢查：該去的具名地點是否都有條目內導航。
- 確認頁尾只剩完整路線或官方資訊，沒有重複的單點導航。
- 檢查所有外部連結皆為 HTTPS、可辨識目的地、使用新分頁與 `noopener`。
- 檢查公開頁面沒有訂位代碼、付款資料、私人電話或其他敏感資訊。
- 更新 CSS 快取版本，完成本機版面與連結檢查後再發布。
