# NZ 2026｜南島公路手札

手機優先的靜態 HTML 旅遊手札，設計基準為 9:19.5，針對 iPhone 13 Pro 與 iPhone 17 Pro 的 Safari 顯示區域調整。

## 本機預覽

```bash
python3 -m http.server 8000
```

瀏覽器開啟 `http://localhost:8000/`。手機可左右滑動，桌機可用左右方向鍵；底部圓點及箭頭也能換頁。

## 發布安全

根目錄的 DOCX、PDF、EML 是私人行程來源，已由 `.gitignore` 排除。發布前仍應執行：

```bash
git status --short
```

確認電子機票、訂位信、訂位代碼及付款資訊沒有被加入版本控制。

## 資料狀態

- 航班、租車、住宿及 RealNZ 活動：依使用者提供文件整理。
- 餐廳與店家營業時間：屬於規劃資訊，出發前應再次確認。
- 公路、步道及天候：請於每日出發前開啟網站內的官方連結檢查。
